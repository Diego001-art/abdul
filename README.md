# Бутри — легенды гор (браузерная RPG)

Игра от третьего лица в стиле «Готики» по реальному селу Бутри (Дагестан).
Рельеф — настоящие высоты, дома и дороги — из OpenStreetMap.

## Как запустить
Локально: в папке репозитория выполнить `python3 -m http.server` и открыть http://localhost:8000

## Управление
WASD — ходить · Shift — бег · Пробел — прыжок · зажать мышь — крутить камеру · колесо — приближение · E — говорить/подобрать · I — сумка · J — квесты · M — карта с секторами

## Карта папок (говорите Claude, какую папку дорабатывать)

| Папка / файл | Что там | Пример просьбы |
|---|---|---|
| `photos/` | Ваши фото села | «Сделай дом №123 как на фото dom1.jpg» |
| `data/sectors.json` | Заметки по секторам (A1…H8, по 250 м) | «В секторе C3 стоит мечеть» |
| `data/places.json` | Пещера змея, камень нарта, башня, родник | «Перенеси пещеру в сектор A1» |
| `data/npcs.json` | Жители: имя, где стоят, одежда | «Добавь кузнеца в D4» |
| `data/quests.json` | Квесты и диалоги | «Добавь квест про кузнеца» |
| `data/houses/houses.json` | Названия, этажи, цвета домов; дома, которых нет в OSM | «Назови дом №123 "Мечеть", 2 этажа» |
| `data/items.json` | Что можно собирать и сколько | «Добавь ягоды, 30 штук» |
| `data/i18n/ru.json`, `dargin.json` | Все тексты на русском и даргинском | «Вот перевод на даргинский: …» |
| `data/terrain/` | Карта высот (рельеф) | «Расширь карту до 5 км» |
| `src/world/` | Земля, дома, дороги, деревья, небо | «Добавь реку», «Сделай ночь» |
| `src/player/` | Герой, камера, управление | «Сделай героя в бурке», «Добавь меч» |
| `src/npc/` | Как выглядят и ведут себя жители | «Пусть жители ходят» |
| `src/systems/` | Сумка, собирательство, квесты, языки (позже: бой) | «Добавь крафт» |
| `src/ui/` | Надписи и окна на экране | «Сделай сумку с ячейками» |
| `lib/` | Движок three.js — не трогать | |

## Номера домов
Подойдите к дому — сверху появится «Дом №…». Этот номер вписывается в `data/houses/houses.json`.

## Если дома не появились
Дома скачиваются из OpenStreetMap при запуске. Если интернета нет или сервер занят, появится сообщение.
Дома, которых не хватает, можно нарисовать на openstreetmap.org — они сами появятся в игре.

## Сектора
Карта 2×2 км поделена на 64 сектора: буквы A–H с запада на восток, цифры 1–8 с севера на юг.
Текущий сектор показан под мини-картой. Говорите: «в секторе E4 добавь мечеть», «в B6 речка».

## Квесты
1. **Горный змей** (главный) — старейшина Абакар, пещера в секторе B2.
2. **Камень нарта** — пастух Магомед, камень в G3.
3. **Ночной дух** — бабушка Патимат, старая башня в C7.
Над жителем жёлтая стрелка — у него есть для вас дело. Прогресс сохраняется в браузере.
