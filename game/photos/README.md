# Фото села

Положите сюда фото. Удобно называть так:
- `dom-<номер дома>-1.jpg` — фото конкретного дома (номер видно в игре, когда подходишь к дому)
- `mechet-1.jpg`, `rodnik-1.jpg`, `shkola-1.jpg` — важные места
- `tekstura-kamen-1.jpg` — близкие фото стен, камня, крыш (для текстур)
- `gory-1.jpg` — горы вокруг

Если не знаете номер дома — просто подпишите, что на фото, и где примерно стоит.
